## 🚀 Tech Stack

This portfolio is built using:

* **React + Vite** — For fast and modern frontend development
* **TypeScript** — For cleaner, safer code
* **Tailwind CSS** — For highly customizable and responsive UI
* **Vercel** — For instant deployments and CDN-backed hosting
* **EmailJS** — For the contact form integration
* **React Icons / Lucide Icons** — For clean iconography

## 🛠️ Running the Project Locally

Clone the repo:

```bash
git clone <repo-url>
cd <repo-folder>
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The app will run at:

```
http://localhost:5173
```

---

## 🔑 Environment Variables (EmailJS)

Create a `.env` file in the root:

```
VITE_EMAILJS_SERVICE_ID=your_service_id
VITE_EMAILJS_TEMPLATE_ID=your_template_id
VITE_EMAILJS_PUBLIC_KEY=your_public_key
```

Restart your dev server after adding env variables.
